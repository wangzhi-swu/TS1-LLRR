# TS1-LLRR

Matlab Code for subspace clustering:

Reference: Dong Hu, Qin Qu, Zhuo Liu, Wu Chen, and Zhi Wang*. Subspace clustering based on latent low-rank representation with
transformed Schatten-1 penalty function, Knowledge-Based Systems, 2024.

This code was developed by Qin Qu under the supervision of Dr. Zhi Wang at Southwest University, 2022.

For algorithm interpretation, please read our paper, in which more details are demonstrated.
